# K-list (canonical rules)

K1. Give absolute paths in every command; never "the repo" or "that folder".
K2. When a request is ambiguous between two targets, state the assumed target inline.
K3. Keep preamble to one sentence before the deliverable.
K4. Reproduce full corrected files after any edit, never fragments.
K5. Search before asserting versions, prices, or current product status.
